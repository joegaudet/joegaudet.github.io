harnessed

Test harnesses for components and pages. Write one once and it drives your component in jsdom, Playwright, Cypress, Ember, WebdriverIO and more.

class LoginFormHarness extends ComponentHarness {
  @ByLabel('Email') private accessor email!: Query

  async signInAs(email: string, password: string) { … }
}

// the same class, in jsdom or a real browser
await new LoginFormHarness(pw(page)).signInAs(…)

real-enums

Enums that are real classes. The label, the CSS class, or what comes next lives on the value, not in an if/else ladder in every template. Adapters for WarpDrive, TanStack Query, SWR, RTK Query, Apollo and urql.

class OrderState extends Enum {
  static Pending = new OrderState('pending')
  static Shipped = new OrderState('shipped')

  @is() accessor isPending!: boolean
  get className() { return `badge badge--${this.value}` }
}

Formwright

Declarative, accessible forms for Ember. Labels, ids, errors, aria-invalid, dirty state and nested saves are handled; bring any Standard Schema validator and any data layer.

<Form @model={{@user}} @validator={{userSchema}} @onSubmit={{@save}} as |f|>
  <f.Field @for="email" @control="email" @label="Email" />
  <f.Field @for="plan" @control="select" @options={{@plans}} />
</Form>
